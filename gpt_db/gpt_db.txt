우선순위| 수집 대상| 목표 개수| 용도
1| 도매식품 공급처| 20개| 메뉴 재료 링크
2| 포장재 공급처| 10개| 배달 원가 계산
3| 주방기기 공급처| 5개| 창업 준비물
4| 배달/물류 링크| 5개| 배달 운영안
5| 릴스/홍보 외주자| 10개| 홍보센터
6| 구인 플랫폼| 5개| 직원 공고문 연결
7| 브랜드 참고 데이터| 30개| AI 브랜드 생성 참고
8| 문제제기 기사| 10개| 홍보 콘텐츠

6-2. 수집 방식 원칙

- 무단 대량 크롤링 금지
- 실제 링크는 수동 수집, 공공데이터, 사용자가 제공한 링크, 제휴 가능 업체 우선
- 외부 플랫폼의 이미지·로고·유료 정보는 복제하지 않음
- 가격은 "estimated_price.note"에 “추정값” 또는 “확인 필요” 표시
- 실제 공급처 확인 전에는 "confidence_score"를 0.5~0.7 이하로 둠AI 프롬프트 묶음 + 화면별 문구

2-3. 원가 계산 기준

식품 원재료비 = 메뉴에 들어가는 식품 재료 원가 합계

포장비 = 용기 + 뚜껑 + 수저/냅킨 + 배달봉투

식품 원가율 = 식품 원재료비 / 판매가

기초 매출총이익 = 판매가 - 식품 원재료비 - 포장비

배달 가중 수수료 = 판매가 × 배달앱 수수료율 × 배달 주문 비중

공헌이익 = 판매가 - 식품 원재료비 - 포장비 - 배달 가중 수수료

추정 영업마진 = 공헌이익 - 인건비 배분 - 임대료 배분 - 기타비 배분

손익분기 월 판매량 = 월 고정비 / 1인분 공헌이익

손익분기 일 판매량 = 손익분기 월 판매량 / 월 영업일수

4. 1차 데모 고정 결론

1차 데모는 “모든 F&B 창업 자동화”가 아니다.

정확한 목표는 다음이다.

부산 대학가에서 고기 덮밥집을 창업하려는 사람이
예산과 목표 매출을 입력하면
AI가 우삼겹 덮밥 메뉴를 추천하고,
1인분 원가를 계산하고,
공급처 링크를 붙이고,
브랜드와 인테리어 초안을 만들고,
직원 공고문과 배달앱 소개문, 릴스 홍보안을 생성하고,
수입산 우삼겹 공동구매 후보까지 보여주는 웹앱 데모.

이 흐름 하나가 완성되면,
그다음부터 메뉴·지역·공급처를 확장한다.
